# 手機滿版導覽與葉環互動設計

## 目的

修正手機版開啟導覽時露出左側舊頁、導覽面板未覆蓋完整畫面，以及面板底部 LINE／電話按鈕造成視覺擁擠的問題。導覽改為獨立的全螢幕品牌目錄，保留四個網站入口。

## 範圍

- 僅在 `max-width: 768px` 的開啟狀態套用。
- 導覽面板固定覆蓋整個視窗（`100dvh`／`100vw`），不顯示舊頁邊緣或背景圖片。
- 移除面板內的 `.site-nav__contacts`；首頁與手機底部既有聯絡入口不在本次變更範圍。
- 導覽四列右側改為深淺綠「葉環」圖示：預設為淡綠內圈、深綠外環與葉片節點；hover、鍵盤 focus 與 active 時以輕微旋轉、加深底色回饋互動。
- 支援 `prefers-reduced-motion`，減少動態轉場。

## 視覺結構

1. 頂部：品牌、關閉按鈕與細分隔線。
2. 中段：`MENU / 網站導覽` 與四個完整寬度選項列。
3. 底部：僅品牌英文與低對比弧線，不再放聯絡行動按鈕或宣傳圖片。
4. 色彩：深綠作為互動主色、鼠尾草淺綠作為背景、暖金僅作細節，不增加黑金主按鈕。

## 互動與可及性

- 既有開關、Esc 關閉、Tab 焦點循環與路由點擊後關閉選單行為維持。
- 面板開啟時背景不可互動。
- 葉環是裝飾性圖示，不新增額外焦點；整列連結為唯一互動目標。

## 驗證

- 在本機用手機寬度檢視導覽開啟後是否無背景露出、沒有面板內 LINE／電話按鈕、四個選項皆可點擊。
- 不新增測試套件；只執行靜態建置檢查，且不部署。
