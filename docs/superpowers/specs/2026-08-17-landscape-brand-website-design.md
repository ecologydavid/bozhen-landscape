# 柏鎮園藝假山水 React 形象報價網站設計規格

- 日期：2026-08-17
- 狀態：設計已核准，等待規格文件最終審閱
- 第一版類型：React JavaScript 靜態網站

## 1. 專案目標

建立一個兼具精品形象與詢價轉換能力的官方網站。網站先以高品質作品視覺建立專業信任，再引導訪客填寫簡短報價表單，或透過 LINE、Email 聯絡。

第一版只完成靜態頁面、前端互動、表單驗證與完整響應式設計。所有案例圖片使用示意素材；報價送出、LINE、Email 等外部功能暫不串接正式服務。

## 2. 目標客群

網站同時服務兩類客群，但首頁敘事優先面向住宅客戶：

1. 私人住宅、別墅與透天屋主。
2. 企業、建設公司、社區及商業空間業主。

## 3. 服務範圍

網站固定呈現四項核心服務：

1. 庭園設計
2. 植栽綠化
3. 假山水景
4. 後續養護

## 4. 第一版範圍

### 包含

- React JavaScript 靜態網站
- 首頁、案例總覽、案例內頁及 404 頁面
- 響應式桌機、平板與手機版面
- 示意案例資料與圖片
- 案例類別篩選
- 簡短報價表單及前端欄位驗證
- LINE、Email 與報價按鈕的示意互動
- 淡入、圖片縮放與導覽列狀態變化
- 鍵盤操作、色彩對比、替代文字及減少動畫設定

### 不包含

- 真實表單提交或後端資料庫
- LINE、Email、CRM、GA4、Meta Pixel 或廣告平台串接
- CMS 後台
- 會員、登入、付款或即時估價計算
- 正式公司圖片與最終文案

## 5. 網站路由

| 路由 | 用途 |
|---|---|
| `/` | 單頁形象首頁與報價入口 |
| `/projects` | 全部案例及類別篩選 |
| `/projects/:slug` | 個別案例完整介紹 |
| `*` | 品牌化 404 頁面 |

## 6. 首頁資訊架構

首頁採「作品先行、報價收尾」順序：

1. **Header**：品牌名稱、服務、案例、關於、報價導覽。
2. **Hero**：全幅庭園示意圖片、品牌主張、服務摘要、取得報價 CTA。
3. **Services**：四項核心服務與簡短價值說明。
4. **Featured Projects**：三至四個精選案例，連結至案例內頁。
5. **Brand Story**：職人工法、自然比例、空間與生活關係。
6. **Work Process**：需求了解、現場評估、規劃報價、施工、養護。
7. **Client Types / Trust**：住宅、別墅、社區、商業空間及服務承諾。
8. **Quote Form**：簡短單頁報價表單。
9. **Contact Actions**：LINE 與 Email 次要聯絡入口。
10. **Footer**：網站導覽、服務項目與示意聯絡資訊。

手機版在畫面下方提供固定「取得報價」按鈕，點擊後捲動至報價區。

## 7. 案例頁面

### 案例總覽 `/projects`

- 頁面主標與品牌簡介
- 類別篩選：全部、住宅庭園、植栽綠化、假山水景、商業／社區
- 編輯式錯落案例網格
- 每張案例顯示類別、名稱、地區與簡述
- 頁尾報價 CTA

### 案例內頁 `/projects/:slug`

- 大型主視覺
- 案例名稱、類別、地區與服務內容
- 業主需求與設計重點
- 施工前後示意對照
- 植栽、材料與水景說明
- 圖片集
- 相關案例
- 返回案例總覽與前往報價按鈕

## 8. 視覺系統

設計方向為「森林精品」，強調沉穩、自然、職人工藝與高價值感。

### 色彩

| 角色 | 色彩 |
|---|---|
| 主色 | 深森林綠 `#153528` |
| 深色背景 | 墨綠 `#0E2118` |
| 主背景 | 暖米白 `#F3EFE3` |
| 輔色 | 苔蘚綠 `#71806A` |
| 點綴 | 黃銅金 `#B89B62` |
| 主要文字 | 深墨綠 `#17271F` |
| 淺色文字 | 象牙白 `#F7F2E8` |

### 字體

- 標題：Noto Serif TC，營造自然與職人工藝感。
- 內文與介面：Noto Sans TC，確保中文閱讀清楚。
- 字體載入失敗時使用系統 serif / sans-serif 備援字體。

### 構圖原則

- 使用大型庭園攝影、自然石、水流與植栽細節。
- 以留白和比例建立精品感，不大量使用圓角卡片或陰影。
- 案例採大小錯落的編輯式網格。
- 黃銅金僅用於 CTA、細線及小型標示。
- 所有示意圖片集中管理，方便日後替換成 Google Drive 正式素材。

## 9. 互動設計

- 導覽列初始透明，捲動後轉為深綠背景。
- 導覽項目平滑捲動至首頁對應區塊。
- 內容進入可視範圍時輕微淡入及上移。
- 案例圖片 hover 時慢速放大並顯示標題。
- 案例篩選不重新載入頁面。
- 手機固定報價 CTA 點擊後定位至表單。
- 所有動畫支援 `prefers-reduced-motion`。

## 10. 報價表單

表單欄位：

- 姓名（必填）
- 電話（必填）
- 地區（必填）
- 需求類型（必填）
- 預算範圍（必填）
- 需求說明（選填）
- Email（選填）

第一版只執行前端驗證。通過驗證後顯示「目前為網站示意版本，正式上線後開放送出報價」訊息，不顯示假的成功送出狀態。

LINE 與 Email 按鈕同樣攔截導向，顯示「正式上線時開放」提示。後續串接時只替換各按鈕的設定與表單提交處理，不重做版面元件。

## 11. React 技術架構

- React JavaScript
- Vite
- React Router 的 BrowserRouter
- 原生 CSS 與 CSS Variables
- 原生 Intersection Observer
- 不導入制式 UI 元件庫或動畫套件

正式部署需設定 SPA fallback rewrite，讓 `/projects` 與 `/projects/:slug` 直接開啟或重新整理時仍回傳 `index.html`，再交由 React Router 顯示正確頁面。

## 12. 資料設計

靜態內容集中放置於資料模組：

```text
src/data/services.js
src/data/projects.js
src/data/processSteps.js
src/data/siteContent.js
```

案例資料至少包含：

- `slug`
- `title`
- `category`
- `location`
- `summary`
- `heroImage`
- `gallery`
- `clientNeed`
- `designApproach`
- `materials`
- `featured`

首頁只讀取 `featured: true` 的案例；案例總覽讀取全部資料；案例內頁依 `slug` 查找內容。

## 13. 錯誤與備援狀態

- 圖片載入失敗時顯示品牌色背景、案例名稱與備援圖示。
- 不存在的案例網址顯示 404 頁面，不留白或產生執行錯誤。
- 表單錯誤直接顯示在欄位旁，並將焦點移至第一個錯誤欄位。
- 外部連結未設定時不離開目前頁面，改顯示明確提示。
- JavaScript 無法載入時透過 `noscript` 顯示明確說明，不呈現空白頁面。

## 14. 響應式規則

- 桌機：大型主視覺、錯落案例網格、寬版敘事留白。
- 平板：縮減欄數並保持案例層次。
- 手機：單欄內容、可展開導覽、固定報價 CTA、較短動畫距離。
- 主要測試寬度：1440、1024、768、390、360 像素。

## 15. 驗證與完成標準

### 建置

- 依賴安裝成功。
- 開發伺服器可啟動。
- Production build 無錯誤。
- 無 ESLint 阻斷問題。

### 功能

- 首頁導覽及平滑捲動正常。
- 案例類別篩選正常。
- 所有案例卡片可開啟正確內頁。

- 五個目標寬度沒有水平溢位。
- 導覽列、手機選單與固定 CTA 不遮擋內容。
- 文字與背景符合可讀性要求。
- 所有互動可使用鍵盤操作。
- 圖片均有適當替代文字。
- 減少動畫設定生效。
- 實際瀏覽器檢查首頁、案例總覽、案例內頁與 404 頁面。
