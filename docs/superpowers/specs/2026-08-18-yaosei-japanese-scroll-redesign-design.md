# 曜聖景觀「一屏一景」日式編輯風改版設計規格

日期：2026-08-18

狀態：設計已逐段確認，待使用者最終規格審閱

適用專案：`bozhen-landscape` React 靜態形象／詢價網站

## 1. 專案目標

在不推翻現有「自然生活精品」版型、不改變已印製名片識別的前提下，將網站提升為具有日式編輯秩序、景觀沉浸感與專業工程可信度的品牌網站。

本次改版的日式感不依靠鳥居、紅日、和室等表面符號，而來自：

- 留白與非對稱編排；
- 現代明體與穩定字重；
- 石、木、水、苔及和紙的色境；
- 「一屏一景」的階段性捲動換景；
- 真實工程照片、庭師工法與長期養護敘事。

網站仍以住宅庭園為首頁主要客群，同時保留商業造景與建築合作的專業感。核心轉換方式為直接電話、LINE 與 Email 聯絡，不恢復報價表單。

## 2. 已確認的核心決策

1. 保留目前單頁首頁＋獨立案例頁的資訊架構。
2. 採用「作品先行，聯絡收尾」的內容順序。
3. 採用 B「一屏一景」動態強度：有明顯層次，但不炫技、不劫持捲動。
4. 首頁五景依序為：植物 → 石組 → 水景 → 造景 → 養景。
5. 手機維持圓角白色畫布；桌機採更寬廣的景觀型錄編排。
6. 圖片及卡片圓角主要使用 8–10px，不使用大面積 50% 膠囊圓角。
7. 名片 Logo、公司名稱、橘金太陽及灰白識別不變。
8. Google Drive 的真實工程素材經人工初選、自然修美與人工核准後才能上站。
9. 動態屬漸進增強；動畫失效時，所有作品、服務與聯絡資訊仍完整可用。

## 4. 視覺語言

### 4.1 字體

避免過細的新細明體及網格內容缺乏份量。

- 展示標題：現代明體／`Noto Serif TC`，字重 600；
- 內文：`Noto Sans TC`，字重 450–500；
- 導覽、按鈕、標籤：`Noto Sans TC`，字重 700；
- 英文與數字輔助：`Manrope`，字重 600–750；
- 書寫感字體只可少量出現在品牌引言，不作長篇內文或操作介面。

字級使用流動尺度 `clamp()`，避免桌機過大、手機擠壓或標題意外斷行。電話、LINE 與主要按鈕文字一律 `white-space: nowrap`。

### 4.2 色彩

核心色：

- 名片灰：`#5C5C5C`；
- 名片橘金：`#EFA94A` 附近，實作前以名片素材取樣校正；
- 和紙白：`#F3F1E9`；
- 墨色：`#18221C`；
- 苔綠：`#365A45`；
- 石色：`#C9C4B9`；
- 水霧：`#75857D`。

和紙、墨與苔作大面積主色；橘金與水霧只佔約 5–10%，作焦點與層次。

### 4.3 幾何與陰影

- 圖片、卡片、導覽畫布：8–10px 圓角；
- 一般按鈕：6–8px，主按鈕可使用非對稱葉形轉角；
- 不讓所有區塊浮起，只有互動、主照片及重要內容使用柔和陰影；
- Hover 時陰影加深幅度有限，避免電商卡片感；
- 葉形、葉脈、水紋及線稿屬低對比輔助，不搶作品照片。

### 4.4 葉片與小型圖示

使用者提供的植物 icon 案例作為輪廓與語意參考，不直接複製圖檔。正式網站的小葉片、小按鈕及養護提示優先使用同一套客製化 SVG icon，不用 CSS 橢圓硬切成主要葉形。

- 優先語意：嫩芽、單葉、雙葉、植栽、澆灌、修剪、守護、循環養護；
- icon 維持相同視覺重量、端點與填色規則，不混用多套風格；
- 建議尺寸為 16–22px，使用 `currentColor` 配合 hover、active 與深淺背景；
- 裝飾性 icon 使用 `aria-hidden="true"`；若 icon 是按鈕唯一內容，必須提供可讀名稱；
- SVG 可作輕微位移、旋轉或描線動態，但不進行複雜逐路徑動畫；
- CSS 仍可用於延伸弧線、葉脈、遮罩與漸變，不負責繪製主要圖示輪廓。

## 5. 首頁內容與五景架構

### 5.1 植物／Hero

- 保留現有左右分欄主視覺與品牌標題；
- 文字位置略微上移；
- 右側作品照完整填滿預定比例，不出現大面積假性空白；
- 主要行動：瀏覽庭園作品、LINE 諮詢、撥打電話；
- 桌機非對稱，手機回到單欄圓角畫布。

### 5.2 石組／精選作品

- 首頁先展示 3–4 件代表作品；
- 採一大兩小或不等比例景觀型錄編排；
- 圖片有明確地區及服務標籤；
- 點入獨立案例頁查看完整圖片、工程範圍、服務與維護資訊。

### 5.3 水景／服務內容

- 四項服務：庭園設計、植栽綠化、假山水景、後續養護；
- 移除空洞的 01–04 白色網格感；
- 改用有材質、深淺、局部影像與 Hover 回饋的卡片；
- 編號為索引，不作大面積視覺主角。

### 5.4 造景／服務流程

- 五階段：需求了解、現場評估、規劃報價、專業施工、後續養護；
- 使用石徑／庭園路徑式時間線，不使用空白方格；
- 桌機橫向路徑，手機轉為縱向，閱讀順序一致。

### 5.5 養景／品牌與聯絡

- 暮光暖金色境收尾；
- 呈現曜聖的長期養護承諾與完整公司名稱；
- 直接提供 LINE、手機、公司電話、Email、地址與必要公司資料；
- 不顯示詢價表單。

## 6. 一屏一景捲動系統

### 6.1 桌機

- 關鍵段落短暫固定約 0.8–1.2 個 viewport；
- 作品照片交疊切換；
- 前景文字、葉脈或水紋只做 3–5% 的輕視差；
- 不使用 scroll hijacking，不改變滑鼠及觸控板的自然捲動速度；
- 每景由三層組成：環境底色、作品影像、文字／線稿。

### 6.2 手機

- 取消長時間 pin 及多層重型視差；
- 保留背景換色、照片交疊及 12–18px 的輕位移；
- 首屏載入與導覽操作優先於動畫；
- 不因動畫建立固定高度空白區。

### 6.3 低動態與失效備援

- 遵守 `prefers-reduced-motion`；
- 低動態版本取消錯開、視差及背景影片，保留即時顏色、外框與焦點回饋；
- JavaScript 失效時不隱藏任何核心內容；
- 慢速網路先顯示圖片／影片封面。

## 7. 連續漸變與轉景規則

五個章節共用一層環境背景，內容區塊多為透明或半透明，不使用五塊互相切斷的純色 section。

四段過橋色：

1. 和紙 → 暖石灰：先降低暖白亮度，再進入砂岩灰；
2. 石 → 苔：以低彩鼠尾草綠銜接石材與植栽；
3. 苔 → 墨：逐步收暗綠色，不直接切黑；
4. 墨 → 暮金：經過木褐與橄欖棕，模擬夕陽落在石材上的光線。

每次轉景保留約 12–18% 的捲動交疊：

1. 環境底色先開始漸變；
2. 舊照片淡出；
3. 新照片淡入；
4. 標題與線稿最後接棒。

避免高彩度綠、突兀亮金及直線式硬邊色帶。必要時使用多層 linear gradient 與 radial gradient，形成自然光影，而非單一兩色漸層。

## 8. 手機導覽與聯絡元件

### 8.1 展開導覽

- 選單由頁首向下揭開，約 220–280ms；
- 展開後內容立即接續，不在左上方或主圖上方保留空白；
- 頁面背景鎖定，避免雙重捲動；
- 四個選項相隔 35–45ms 依序入場；
- 每列至少 56px 高，整列皆可點擊；
- 使用編號、現代明體中文標題及英文小標，形成日式目錄秩序。

### 8.2 選項 Hover／Touch／Focus

不使用整列大面積墨綠反白。視覺回饋集中於標題至箭頭之間：

- 半透明苔綠局部葉影；
- 1px 橘金延伸線；
- 標題位移約 7px；
- 編號位移約 3px；
- 葉形箭頭框由 -18° 回正並輕微放大；
- 動畫約 250ms；
- 觸控在 touch-down 顯示約 120–160ms 回饋，再執行導覽；
- `focus-visible` 必須具有等價清楚狀態；
- 支援 `aria-expanded`、Escape 關閉，選擇後焦點移至目的章節標題。

### 8.3 LINE／撥打電話雙葉元件

- LINE 約佔 54–56%，電話約佔 44–46%；
- LINE 為墨綠實心主葉，電話為和紙白描邊副葉；
- 電話按鈕向下錯位約 8–9px，兩片葉自然交疊；
- 外框上方加入低對比延伸弧線；
- 按鈕內使用同系列 SVG 葉片 icon、葉脈線稿及橘金嫩芽焦點；
- 圓角為非對稱葉形，不是普通矩形或 50% 膠囊；
- Hover 輕微上移、陰影增強；按壓縮放至約 98%；
- 文字永不換行，觸控範圍符合可用性要求。

### 9.1 素材進站流程

1. 雲端盤點：依工程名稱、地區、服務與檔案型別建立清單；
2. 人工初選：每案挑 3–8 張／段，排除重複、失焦及敏感內容；
3. 自然商業修美；
4. 網站與社群尺寸轉檔；
5. 產生修美前後對照；
6. 人工核准後才進入正式素材庫。

不修改、不移動 Google Drive 原始檔。網站只存放核准後的優化副本。

### 9.2 自然商業修美邊界

允許：

- 曝光、白平衡、色溫、透視、雜訊、銳利與天空品質；
- 移除垃圾、電線碎屑等小型非工程雜物；
- 統一同系列照片的綠色與石材色溫。

禁止：

- 新增不存在的植栽、假山、水景或建物；
- 改變實際完工範圍、植栽種類或工程結果；
- 造成對客戶或工程內容的誤導。

### 9.3 輸出格式

- 首頁主圖：AVIF＋WebP，桌機／手機雙裁切；
- 作品卡：多尺寸 WebP／AVIF，使用響應式載入；
- 背景動態：MP4＋WebM，靜音短循環及 poster 封面；
- 社群預覽：1200×630，保留品牌安全區；
- 原始 HEIC／MOV 永久保留於 Google Drive。

## 10. 響應式、效能與無障礙

### 10.1 響應式

- 必測寬度：360、390、430、768、1024、1280、1440、1920px；
- 360–1920px 不得產生水平捲軸；
- 圖片預先定義 aspect ratio，避免載入後位移；
- 使用可調整的 `object-position` 保留人物、主樹、石組或水景焦點；
- 電話、LINE、導覽及主要按鈕文字不換行；
- 手機導覽展開、關閉、回上一頁及路由切換都需測試。

### 10.2 效能目標

- LCP ≤ 2.5s；
- CLS ≤ 0.10；
- INP ≤ 200ms；
- 首屏以靜態封面優先，非首屏作品與影片延遲載入；
- 不用大型動畫函式庫完成可由 CSS／Intersection Observer 實現的效果；
- 動畫避免高成本大範圍 blur、filter 及 layout 變更，優先使用 transform／opacity。

### 10.3 無障礙

- 一般文字對比至少 4.5:1；
- 所有互動元件具清楚的 hover、focus-visible、active 狀態；
- 圖片提供符合工程內容的替代文字；
- `tel:`、LINE 與 `mailto:` 使用正確語意；
- 行動目標尺寸符合觸控需求；
- 動態背景不得妨礙文字閱讀。

## 11. 案例頁

案例頁維持獨立路由，沿用首頁的字體、色境及 8–10px 幾何語言，但降低動態密度，讓照片與工程資訊成為主角。

每個案例至少包含：

- 專案名稱、地區及服務類型；
- 精選照片／影片；
- 需求或現場條件；
- 主要工法與材料；
- 完工結果；
- 維護建議；
- 電話與 LINE 聯絡入口。

若沒有可靠的前後對照或工程資訊，不得虛構。

## 12. 非目標

本次改版不包含：

- 後端報價表單或 CRM 串接；
- 社群自動發文系統；
- GA4、Meta Pixel 或廣告歸因的完整導入；
- 自動從 Google Drive 即時同步公開網站；
- 修改名片設計；
- 自動發布未經人工審核的 AI 修美內容。

上述功能可在視覺改版穩定後另立規格與實作計畫。

## 13. 驗收標準

設計與實作完成時，至少符合以下條件：

1. 名片 Logo、名稱、灰白橘金識別及正式聯絡資訊正確保留；
2. 首頁五景順序清楚，轉景具有連續過橋色，無突兀純色斷點；
3. 桌機有一屏一景效果，手機為順暢的輕量版本；
4. 手機導覽無大面積空白、無雙重捲動，選項具有精緻互動；
5. 雙葉 LINE／電話按鈕比例、線條、錯位及狀態符合規格；
6. 所有電話與按鈕文字不換行，圖片及 Hero 不破版；
7. 服務與流程不再呈現空洞數字網格；
8. Google Drive 原始檔未被改動，網站素材均有人工作業紀錄與核准；
9. 360–1920px 無水平溢位，主要瀏覽器與觸控操作正常；
10. 低動態與 JavaScript 失效時，核心內容與聯絡功能仍可用；
11. 效能與無障礙指標達到第 10 節目標；
12. GitHub Pages 正式部署後執行桌機與手機 smoke test。

## 14. 設計參考原則

本案參考日本景觀與庭園公司的作品呈現方式，不直接複製其版面：

- Daiichi Engei：設計、施工與養護的完整服務敘事；
- Ueyakato Landscape：創造庭園與養育庭園並重；
- Shiono：傳統材料、深度與寧靜空間；
- Nakane Garden：依場地與委託需求提升庭園藝術性；
- Nomura Landscape：精準空間構成與多類型案例表達。

最終視覺仍以曜聖的名片識別、真實工程與台灣住宅／商業客群為中心。
